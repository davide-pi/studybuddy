# StudyBuddy 📚

App per studiare con le flashcard e i quiz!

## Funzionalità

- ✅ Mazzi di carte divisi per materia
- ✅ Flashcard con ripetizione spaziata (metodo Leitner)
- ✅ Quiz a risposta multipla a tempo ⏱️
- ✅ Ricerca nelle carte
- ✅ Import da CSV
- ✅ Statistiche dei quiz
- ✅ Login utenti
- 🚧 Export in PDF (in arrivo)

## Come avviarlo

```
cd StudyBuddy
dotnet run
```

Poi apri http://localhost:5000
